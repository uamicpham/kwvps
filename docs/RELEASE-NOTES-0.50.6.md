# KwVPS 0.50.6 — token Cloudflare theo site và backup token mã hóa

- Cloudflare dùng API token riêng cho từng site thay vì token chung hoặc token theo zone. Trong **Công cụ nâng cao → Bảo mật/Cloudflare → Cấu hình API token**, chọn site, nhập token; KwVPS xác minh token rồi thử tự tìm Zone ID. Nếu thiếu token khi bật tự đẩy IP bị Nginx giới hạn, menu hướng dẫn cấu hình token trước và không hỏi Zone ID. Chỉ đề nghị nhập Zone ID thủ công khi đã có token nhưng không tự tìm được.
- Token chung và token theo zone của bản cũ **không còn được dùng làm phương án dự phòng**. Các file cũ không bị tự xóa. Sau khi nâng cấp, bridge tự đẩy IP của site chưa có token riêng sẽ **tạm dừng và ghi cảnh báo trong journal**; rate limit Nginx local vẫn hoạt động. Cấu hình lại token cho từng site để dùng Under Attack, Cloudflare Rate Limiting và tiếp tục bridge. Site dùng hai tài khoản Cloudflare khác nhau có thể lưu hai token khác nhau. Đổi tên miền vẫn từ chối site có token/Zone ID hoặc tài nguyên Cloudflare phụ thuộc; chưa tự di chuyển các tài nguyên đó.
- Worker đọc log Nginx gắn sự kiện với site để chọn đúng token khi gọi Cloudflare. Cơ sở dữ liệu trạng thái cũ được bổ sung cột site; các ban cũ không xác định được site (đặc biệt khi nhiều site cùng zone) có thể còn tồn tại sau 15 phút và cần kiểm tra/xóa thủ công trên Cloudflare. Chức năng đẩy IP vẫn cần kiểm thử trọn quy trình với IP công khai và quyền ghi rule của token: thử qua loopback chỉ xác nhận Nginx trả HTTP 429, không xác nhận Cloudflare đã tạo rule.
- Backup cấu hình domain có Zone ID trong archive và token của site trong file `.cf.enc` mã hóa bằng mật khẩu riêng do quản trị viên đặt (16–128 ký tự), kèm checksum cho từng file. Giữ archive, file mã hóa, hai checksum và mật khẩu khi chuyển máy. Restore kiểm tra checksum, giải mã, xác minh lại token/zone với Cloudflare và yêu cầu site hiện hữu cùng domain/ID, PHP và chế độ HTTP/HTTPS. Backup cấu hình cũ không có token vẫn đọc được.

Backup cấu hình **không phải gói chuyển VPS đầy đủ**: chưa gồm source/code, database, chứng chỉ hoặc khóa SSL, ingress/Tunnel, rate limit, cron và cấu hình dịch vụ chung. Không đặt mật khẩu hay token trong GitHub hoặc chat. PHP 7.4 vẫn đã hết hỗ trợ bảo mật; chỉ dùng cho ứng dụng cũ khi chấp nhận rủi ro.

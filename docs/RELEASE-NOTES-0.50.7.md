# KwVPS 0.50.7 — backup dễ nhận diện và kiểm tra dịch vụ sau thay đổi

Phạm vi cài mới vẫn là Ubuntu Server 24.04 LTS sạch, x86_64 và systemd; không cài đè LarVPS hoặc web stack có sẵn. Chỉ tải bản phát hành khi GitHub Release có đủ gói `.tar.gz` và checksum.

- Backup source và cấu hình domain mới trong `/var/backups/kwvps` mang tên dễ nhận diện: `source-<domain>-YYYYMMDD-HHMMSS[-N].tar.gz` và `config-<domain>-YYYYMMDD-HHMMSS[-N].tar.gz` (UTC). Domain quá dài dùng site ID để không vượt giới hạn tên file. Nếu tạo nhiều bản trong cùng giây, KwVPS thêm hậu tố số và không ghi đè file đã có. Archive mới vẫn có `.sha256`; backup cấu hình có token Cloudflare còn có file `.cf.enc` mã hóa và checksum riêng. Danh sách/chọn/restore tiếp tục nhận archive tên cũ.
- Export DB mới mang tên `db-<tên-DB>-YYYYMMDD-HHMMSS[-N].sql.gz` (UTC), giữ bản cũ và không tạo checksum riêng. Import vẫn nhận dump `.sql`/`.sql.gz` đã tải vào thư mục backup. **Import không tự export hiện trạng DB đích và không nguyên tử**: nếu cần giữ dữ liệu cũ, hãy export DB thủ công trước khi import; lỗi SQL có thể để DB ở trạng thái một phần. Xóa DB vẫn tự export trước khi DROP.
- Ô nhập API token Cloudflare theo site, Tunnel token, mật khẩu tạo/đổi user DB và mật khẩu admin DB của phpMyAdmin nay **hiện ký tự khi nhập**. KwVPS không in lại giá trị sau khi lưu. Không nhập khi đang chia sẻ/ghi hình màn hình hoặc khi người khác có thể nhìn terminal. Token và metadata DB vẫn nằm trong file root-only; mật khẩu admin phpMyAdmin do MariaDB quản lý, không lưu vào cấu hình KwVPS. Mật khẩu **mã hóa backup** và mật khẩu SSH do `passwd` hỏi vẫn nhập ẩn.
- Các thay đổi cấu hình PHP-FPM và Nginx được kiểm tra cú pháp trước khi restart, rồi xác nhận service vẫn active; khi lỗi, đường hoàn tác cũng kiểm tra lại. Đổi PHP version của site kiểm tra socket và, nếu có `public/index.php`, thử HTTP qua loopback trước/sau để phát hiện lỗi mới. Đây không thay thế kiểm thử ứng dụng đầy đủ. Cài extension PHP restart FPM để nạp extension; hook gia hạn SSL KwVPS restart Nginx sau khi kiểm tra cấu hình. Upgrade chỉ thay hook cũ nếu khớp đúng mẫu KwVPS, không ghi đè hook tùy biến.
- Sau cài mới, KwVPS kiểm tra cấu hình Nginx/PHP 8.3 FPM và xác nhận các dịch vụ cốt lõi active. Sau cập nhật package qua menu, KwVPS kiểm tra Nginx và những PHP-FPM đang chạy, đồng thời xác nhận các dịch vụ trước đó active vẫn hoạt động. Menu Update không ép restart dịch vụ lần hai sau APT; script cài package vẫn có thể gây gián đoạn. Nên nâng cấp trong khung bảo trì và kiểm tra website sau đó.

0.50.7 **không** biến backup cấu hình domain thành gói chuyển VPS đầy đủ: source, DB, chứng chỉ/khóa SSL, Tunnel route, rate limit, cron và cấu hình toàn VPS vẫn cần xử lý riêng. Chức năng đẩy IP bị Nginx limit lên Cloudflare chưa được xác minh end-to-end bằng IP khách công khai; phép thử loopback chỉ xác nhận HTTP 429 tại Nginx. Xem [trạng thái chức năng](TRANG-THAI-CHUC-NANG.md) trước khi dùng trên VPS có dữ liệu thật.
